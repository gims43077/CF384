# 현재 배포 모델 — 2026-11-23 / API 1.4.0

## 무엇이 배포되어 있나요?

기본 결과는 `lowres`입니다. **동결 CF384(ViT-S/16) + L2-SP + 기존 증강 + 160~300px 축소 증강으로 학습한 선형 분류기**를 사용합니다. 공식 백본은 설치 시 다운로드하고, 학습한 작은 head 두 개는 저장소의 `models/`에 포함되어 있습니다.

| 구성 | 현재 적용 방법 |
| --- | --- |
| 특징 추출 | 공식 CF384 백본을 동결하고 384차원 특징 추출 |
| 추가 학습 | 384개 계수와 편향 1개인 선형 head, 총 385개 파라미터 |
| L2-SP | 추가 학습 head가 원본 CF384 head에서 과도하게 멀어지지 않도록 규제 |
| 기존 증강 | 원본 입력과 좌우반전·리사이즈·블러·JPEG를 조합한 2개 view |
| 저해상도 증강 | 160~300px 축소를 포함한 2개 view 추가, 총 5개 view를 함께 학습 |
| 최종 head | 4개 fold의 계수와 편향을 동일 가중치로 평균 |
| 추론 | 백본 1회로 original / adapted / lowres 점수 계산, 기본 임계값 0.5 |

저해상도 head는 원본 CF384 head에서 시작해 전체 5개 view로 학습했습니다. 이전 개선 head에 순차적으로 추가 학습한 것이 아닙니다. 최종 head 평균은 WiSE-FT나 sigmoid 점수 평균과 다릅니다. **TTA·LoRA·GAPL·주파수 특징 결합·WiSE-FT는 현재 배포 추론 경로에 포함되지 않습니다.**

## 실제로 얼마나 달라졌나요?

저장된 로컬 측정 결과입니다. 이번 문서 업데이트에서 재학습하거나 새 정확도 평가를 실행하지 않았습니다. Wikimedia Commons의 실제 사진 32장·생성 이미지 32장, 긴 변 160~280px, 임계값 0.5 조건입니다. Google 검색 썸네일 자체를 평가한 결과는 아닙니다.

| 모델 | 정확도 | 정밀도 | 재현율 | F1 | ROC-AUC | 실사 오탐률 | AI 누락률 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 원본 CF384 | 81.25% | 100.00% | 62.50% | 76.92% | 0.9775 | 0.00% | 37.50% |
| 기존 L2-SP + 증강 | 85.94% | 100.00% | 71.88% | 83.64% | 0.9639 | 0.00% | 28.13% |
| 최신 L2-SP + 증강 + 축소 학습 | 90.63% | 93.33% | 87.50% | 90.32% | 0.9697 | 6.25% | 12.50% |

AI 생성이 양성 클래스입니다. 최신 모델의 혼동행렬은 TN=30, FP=2, FN=4, TP=28입니다. 기존 개선 head 대비 오류 5개를 고쳤지만 실사 오탐 2개가 새로 생겼습니다. 정확도 차이 +4.69%p의 paired bootstrap 95% 구간은 −3.13~+12.50%p이므로 확정적 개선으로 해석하면 안 됩니다. 원본 모델의 ROC-AUC는 최신 head보다 높습니다.

같은 썸네일에 JPEG85 압축을 더하면 최신 정확도는 81.25%로 떨어집니다. 표본 크기·생성기·출처가 제한되고 클래스별 파일 형식 차이가 있으며, 사전학습 데이터 미노출도 보장하지 못합니다. 평균 배포 head는 다른 fold에서 특정 생성기를 학습했을 수 있으므로 전체 결과를 미지 생성기 일반화 성능으로 해석하지 않습니다. 점수는 보정된 진위 확률이 아닙니다.

## 이번 GitHub 업데이트의 범위

모델 코드·저해상도 head·API 1.4.0의 무료 Google Lens 연동은 기존 커밋에 이미 반영되어 있었습니다. 이번에는 현재 배포 상태 설명, 이미지별 점수 변화 CSV, 작업 요약의 현재 버전 안내를 정리했습니다. **가중치와 임계값은 변경하지 않았습니다.** 최신 head의 SHA256은 [provenance.json](../models/provenance.json)에서 확인할 수 있습니다.

Google Lens는 CF384 판별 점수와 별개의 이미지 사용처 검색입니다. SerpApi 무료 요금제 확인 후 사용하며 유료 fallback은 없습니다. 실제 계정 키가 없어 검색 품질은 아직 측정하지 않았습니다. [검색 설정과 제한](WEB_USAGE_SEARCH_KO.md).

## 기존 설치 업데이트

저장소 폴더에서 서버를 Ctrl+C로 종료한 뒤 실행합니다.

```sh
git pull --ff-only
.venv/bin/python run_server.py
```

Google Lens도 사용하도록 설정했다면 마지막 명령에 `--enable-web-search`를 추가합니다. Windows에서는 `.venv/bin/python` 대신 `.\.venv\Scripts\python.exe`를 사용합니다. 기존 설치의 로컬 API 키를 사용하고 브라우저를 새로고침하세요. 응답은 `api_version=1.4.0`, 기본 `selected_model=lowres`여야 합니다. 클라이언트가 `model=adapted`를 명시하면 이전 head를 선택하므로 `model=lowres`로 바꾸거나 query를 생략하세요. 새 설치는 [간단 사용법](../QUICK_START_KO.md)을 따르세요.
